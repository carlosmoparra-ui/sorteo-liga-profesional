# Sorteo de Liga Profesional

## Descripción
Aplicación desarrollada en Java para realizar
el sorteo de una liga profesional de fútbol
con 16 equipos participantes.

## Funcionalidades
- Sorteo aleatorio de equipos.
- Emparejamiento recursivo.
- Etapas de octavos, cuartos, semifinal y final.
- Excepciones personalizadas.
- Guardado y carga mediante serialización.
- Arquitectura Modelo-Vista-Controlador (MVC).

## Tecnologías
- Lenguaje Java.
- Programación Orientada a Objetos.
- Manejo de archivos.
- GitHub.
